# FNB Design Technique Reference

## Core rule
This skill is a technique reference, not FNB visual authority.

## Use when
- Evaluating shadows, blur, responsive spacing, container widths, typography hierarchy, glass surfaces, neumorphic depth, or layout proportions in an existing design.

## FNB override
The uploaded reference uses a light `#f5f5f5` background, white neumorphic cards, zinc neutrals, indigo/violet accents, rounded cards and glass pills. Those choices MUST NOT override the accepted FNB system.

For FNB preserve:
- obsidian / carbon-black environment;
- molten orange as signal, not decoration;
- editorial scale and architectural geometry;
- restrained radii and surfaces;
- controlled negative space;
- cinematic imagery;
- typography-led authority.

## Allowed extraction
Codex may reuse the reference's reasoning about:
- multi-layer shadow construction;
- blur/backdrop mechanics;
- spacing discipline;
- max-width constraints;
- mobile-first breakpoint logic;
- type hierarchy and readable measure.

## Prohibited direct imports
Do not introduce the reference's light palette, indigo/violet gradients, pill-heavy UI, white neumorphic card system, or generic rounded-card grids unless an accepted FNB design explicitly requires them.
