## Publication boundary

All 23 runtime portraits come from the approved `14-Team/01-Web-Optimized` set. The source filename metadata is not verified identity, role, biography, consent, or publication data. It must not be copied into public UI without owner approval. Master portraits are prohibited from public runtime use.

## Approval handoff

- Record the owner-approved spelling of each public identity.
- Record the owner-approved current role without deriving it from a filename.
- Confirm portrait and web-publication consent.
- Approve a useful, non-biographical alt text for each portrait.
- Confirm whether each record is publish, withhold, or replace.
- Supply approved biography copy separately if biographies are required.
